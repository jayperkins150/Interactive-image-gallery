# Interactive Image Gallery

An interactive image gallery that allows users to browse and engage with a collection of images through an intuitive and responsive interface.

## Features

- Responsive image grid layout
- Interactive image previews
- Smooth user interactions
- Mobile-friendly experience
- Clean and accessible design

## Technologies Used

- HTML
- CSS
- JavaScript

## Getting Started

### Clone the repository

```bash
git clone https://github.com/jayperkins150/Interactive-image-gallery.git
```

### Run locally

Open `index.html` in your browser.
